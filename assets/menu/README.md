# صور منيو دوبامين

24 صنفًا، لكل صنف صورتان: Plate على الطبق، وPackaging بتغليف شعار دوبامين.

- originals: الصور الأصلية PNG، بأسماء عربية وإنجليزية.
- web: نسخ WebP خفيفة للموقع.
- index.html: معرض للمقارنة بين الصورتين لكل صنف.
- prompts.json: أوامر التوليد الدقيقة ومصدر وحفظ كل صورة. استخدمت أداة image_gen المدمجة.

الصور تصورات أولية وليست تصويرًا للمنتجات الفعلية. تارت Caviar ممثل بحبات شوكولاتة؛ Libanaise تصور حلوى كريمية لبنانية. الوصفات النهائية والأسعار لم تعتمد.
