# لغة الموقع الرسمية

تُكتب النصوص العربية الظاهرة في الموقع بالعربية الفصحى الواضحة، بأسلوب رسمي ومباشر. يشمل ذلك العناوين والوصف والتنقل والبحث والسلة والحجز ومتابعة الطلبات ورسائل النجاح والتحقق والأخطاء ولوحة الإدارة وبيانات مشاركة الرابط.

المصطلحات الموحدة:

- قائمة المنتجات، أو المنتجات في الأزرار المختصرة؛ لا تُستخدم «المنيو».
- سلة التسوق، وأضف إلى السلة؛ لا تُستخدم «الحقيبة».
- علبة، وعلبة هدايا؛ لا تُستخدم «بوكس».
- كرات البروتين، والصلصة، ورقم الهاتف، ومعايير البحث.
- حالات الطلب: بانتظار التأكيد، مؤكد، قيد التجهيز، جاهز، تم التسليم، ملغى.

تُحفظ أسماء المنتجات المعروفة والعلامة التجارية كما هي. تبقى النسخة الإنجليزية متاحة. لا تتغير شروط الطلب أو سياسات الخصوصية أو الأسعار أو مواعيد التجهيز عند تحرير الصياغة. تُترجم رسائل خدمة الطلبات في طبقة العرض، دون تعديل قواعد التحقق أو الاستجابات.
